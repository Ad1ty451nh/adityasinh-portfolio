# Adityasinh Raulji Portfolio

A dependency-light, interactive personal portfolio for Adityasinh Raulji.

## Run

Open `index.html` directly in a browser, or serve the folder with any static server.

## Structure

- `index.html` - semantic page structure and metadata
- `styles.css` - responsive visual system and interactions
- `script.js` - project/skill rendering, terminal commands, reveal effects, custom cursor
- `assets/` - profile photo, resume, and favicon
